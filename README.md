Todo App

React + TypeScript + Supabase(prisma 이용시 query는 ORM이 아닌 native sql 사용)+ 필요시 백엔드 nestjs 로 만든 골프 스크린 및 라운딩, 실내 자전거 운동 기록을 만들어야함
필요한 계정이나 키값은 .env에서 설정하고 필요시 나에게 물어보고 만들어봐


인증 (Authentication)
* 이메일/비밀번호 로그인 및 회원가입
* Google OAuth 로그인 (리디렉션 방식)
* Naver OAuth 로그인
* 세션 자동 유지 (새로고침해도 로그인 상태 보존)
* 오류 메시지 한국어 번역

bicycle 기록 관리 (CRUD)
* 추가: 기본적으로 이번달 달력으로 디폴트 표시하고 bike_aprill.xlsx 참조
* 수정: 체크 박스로 체크 가능하게 하면 됨
* 삭제: 기능은 없음 


* 낙관적 업데이트(Optimistic Update)로 빠른 UI 반응

* 라이트 ↔ 다크 모드 토글 버튼
* 로그인 전/후 모두 사용 가능 (우측 상단 고정 버튼)
* 로그인 상태: 선택한 테마를 DB에 저장 (기기 간 동기화)
* 비로그인 상태: localStorage에 저장 + OS 다크모드 자동 감지
